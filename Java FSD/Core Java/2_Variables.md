## Variables
- A Variable is the named memory location to the stored data

```java 

int Age=21;

```
- int → Data type
- age → Variable name
- 21 → Value stored

### variable Declaration

```Java
int Age;
```
- Int datatype
- Age Variable name

No value assigned

### Variable Initialization

Assign  value too the variable

```java
int Age=21;
```
- this is Declaration + Initialization

### Variable Reassignment

```java
int age=21;
age =22
```
- Now age=22

### Types of variables

- There are 3 types

```java
Variables
│
├── Local Variable
├── Instance Variable
└── Static Variable
```

Variable = Named memory location

Local Variable
→ Inside method
→ Stack Memory

Instance Variable

→ Inside class, outside method

→ Each object has its own copy

Static Variable

→ Shared by all objects

→ One copy for the entire class
