### 1️⃣ What is `foreach`?

The `foreach` statement provides a clean, sequential way to iterate through each item in any enumerable collection without manually managing index counters or boundary conditions.

```csharp
string[] names = { "Tony", "Rahul", "John" };

foreach (string name in names)
{
    Console.WriteLine(name);
}
```

#### Output:
```text
Tony
Rahul
John
```

#### Traversal Flow:
```
names Collection
       ↓
[0] "Tony"   ──> Execute block
       ↓
[1] "Rahul"  ──> Execute block
       ↓
[2] "John"   ──> Execute block
       ↓
Sequence Complete ──> Exit Loop
```

---

### 2️⃣ Anatomy of the `foreach` Syntax

```csharp
foreach (string name in names)
{
    Console.WriteLine(name);
}
```

#### Clause Breakdown:

* **`foreach`**: Keyword initiating the collection iteration statement.
* **`string name`**: Iteration variable declaration holding the current item.
* **`in`**: Keyword separating the loop variable from the target collection.
* **`names`**: The collection or array being traversed.

> **Operational Meaning:** For every element of type `string` inside the `names` array, assign that element to the variable `name` and execute the loop body.

### 3️⃣ Arrays & Zero-Based Indexing

An array is a fixed-size, contiguous data structure storing multiple elements of the same type.

```csharp
int[] numbers = { 10, 20, 30, 40, 50 };
```

Elements are accessed via zero-based bracket notation `[index]`:

```csharp
Console.WriteLine(numbers[0]); // 10 (First element)
Console.WriteLine(numbers[1]); // 20 (Second element)
Console.WriteLine(numbers[4]); // 50 (Fifth element)
```

#### Index vs. Value Layout:
```
Index:    [0]   [1]   [2]   [3]   [4]
Value:     10    20    30    40    50
```

---

### 4️⃣ The `.Length` Property

Arrays expose a read-only `.Length` property returning the total number of elements:

```csharp
int[] numbers = { 10, 20, 30, 40, 50 };
Console.WriteLine(numbers.Length); // Output: 5
```

Because indices are zero-based, the final valid index of any array is always `array.Length - 1`.

### 5️⃣ `for` vs. `foreach` Comparison

Both loops traverse collections, but operate on different mental models:

#### Index-Based Traversal (`for`)
```csharp
int[] numbers = { 10, 20, 30 };

for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}
```

#### Element-Based Traversal (`foreach`)
```csharp
int[] numbers = { 10, 20, 30 };

foreach (int number in numbers)
{
    Console.WriteLine(number);
}
```

| Traversal Model | Key Characteristic | Typical Use Case |
|---|---|---|
| **`for`** | Works with positional index (`i`) | Modifying array in-place, reverse traversal, step skipping, parallel arrays |
| **`foreach`** | Works directly with elements | Reading data sequentially, cleaner syntax, safer iteration |

### 6️⃣ Traversing Strings with `foreach`

In C#, `System.String` implements `IEnumerable<char>`, meaning a string is an iterable sequence of characters:

```csharp
string name = "Tony";

foreach (char character in name)
{
    Console.WriteLine(character);
}
```

#### Output:
```text

n
y
```

### 8️⃣ Combining Iteration with Conditional Filtering

You can nest decision-making statements (`if`) inside collection loops to filter data:

```csharp
int[] numbers = { 10, 15, 20, 25, 30 };

foreach (int number in numbers)
{
    if (number % 2 == 0)
    {
        Console.WriteLine(number);
    }
}
```

#### Output:
```text
10
20
30
```

### 9️⃣ Array of Objects: Enterprise Foundation

In enterprise backend applications (e.g., ASP.NET Core APIs), collections commonly hold reference types and domain models:

```csharp
class Product
{
    public string Name;
    public decimal Price;
}

class Program
{
    static void Main()
    {
        Product[] products =
        {
            new Product { Name = "Laptop", Price = 50000m },
            new Product { Name = "Phone", Price = 30000m },
            new Product { Name = "Tablet", Price = 20000m }
        };

        foreach (Product product in products)
        {
            Console.WriteLine(product.Name);
        }
    }
}
```

*This pattern underpins data-transfer objects (DTOs), database queries via Entity Framework Core, and JSON serialization.*

### 🔟 Core Limitations of `foreach`

1. **Read-Only Iteration Variable:** You cannot reassign the iteration variable directly to alter the array element (`number = 100;` inside a `foreach (int number in numbers)` produces a compile-time error).
2. **No Built-in Index:** If your algorithm requires tracking or calculating positions (e.g., finding the index of an element, swapping values), a standard `for` loop is often cleaner and avoids maintaining external counter variables.

```
Need element position or in-place value substitution? ──> for
Need clean, sequential read-only iteration?           ──> foreach
```
