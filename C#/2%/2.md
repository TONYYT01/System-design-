# DAY 2 — 2%
## `var` + `const` + Type Conversion

Continuing directly from Day 1. These topics form an essential part of the **C# Fundamentals** section of your roadmap.

The goal isn't just to know the syntax—you should understand what C# is doing with types under the hood.

---

### 1️⃣ `var` (Implicit Typing)

`var` allows the compiler to infer (determine) the variable's type directly from the assigned value at compile time.

```csharp
var age = 22;
var name = "Tony";
var salary = 45000.50;
var active = true;
```

C# determines the underlying types:

* `age` $\rightarrow$ `int`
* `name` $\rightarrow$ `string`
* `salary` $\rightarrow$ `double`
* `active` $\rightarrow$ `bool`

> **Important:** `var` does **not** mean "any type" (it is not dynamic).

```csharp
var age = 22; // The compiler locks 'age' as an int

age = "Tony"; // ❌ Compile Error: Cannot implicitly convert type 'string' to 'int'
```

Because `age` is statically typed as an `int`, its type cannot be changed later.

```
var
 ↓
Compiler determines type at compile-time
 ↓
Type remains fixed for the lifetime of the variable
```

---

### 2️⃣ Explicit Type vs. `var`

Both approaches produce the exact same binary output:

```csharp
int age = 22; // Explicit declaration
var age = 22; // Implicitly typed declaration (inferred as int)
```

The difference is readability and developer convenience. As you progress, you will learn when `var` improves readability (e.g., avoiding long redundant constructor calls) and when explicit types clarify intent. For now, focus on the underlying mechanism.

---

### 3️⃣ `const` (Constants)

A `const` represents an immutable value that **cannot be changed** after declaration. It must be assigned a value at compile time.

```csharp
const double PI = 3.14159;

PI = 3.14; // ❌ Compile Error: The left-hand side of an assignment must be a variable
```

Another example:

```csharp
const int MaxUsers = 100;
```

#### Variable vs. Constant

```csharp
int age = 22;
age = 23;          // ✅ Valid (Variable: can change)

const int max = 100;
max = 200;         // ❌ Invalid (Constant: cannot change)
```

---

### 4️⃣ Type Conversion: Implicit Conversion

Conversion occurs when values of different types interact.

**Implicit conversion** happens automatically when the destination type is large enough to safely hold the source value without data loss.

```csharp
int number = 100;
double value = number; // Automatically converts int (4 bytes) to double (8 bytes)
```

```
int ──(safe / no loss)──> double
```

No special cast syntax is required.

---

### 5️⃣ Type Conversion: Explicit Conversion (Casting)

When a conversion might result in data loss or precision truncation, C# requires an **explicit cast**.

Syntax: `(targetType)value`

```csharp
double price = 99.99;
int value = (int)price;

Console.WriteLine(value); // Output: 99
```

> **Note:** The fractional portion is discarded entirely (truncated), not rounded.

Another example:

```csharp
double x = 10.8;
int y = (int)x; // y becomes 10
```

---

### 6️⃣ String $\rightarrow$ Number Conversion

Reading input from a console, UI, or API usually yields a `string`. You must convert these strings to numbers before performing arithmetic.

#### Using `int.Parse()`

```csharp
string input = "100";
int number = int.Parse(input);

// "100" (string) → 100 (int)
```

#### Using `Convert.ToInt32()`

```csharp
int number = Convert.ToInt32(input);
```

Both methods convert valid numeric strings into integers. Later in the roadmap, we will explore error handling and safe parsing patterns like `int.TryParse()`.

### 💻 Day-2 Coding Practice

Create and run the following program:

```csharp
using System;

class Program
{
    static void Main()
    {
        var name = "Tony";
        var age = 22;
        var salary = 45000.50;

        const int maxLoginAttempts = 3;

        // Implicit conversion
        int number = 100;
        double convertedNumber = number;

        // Explicit conversion (casting)
        double price = 99.99;
        int integerPrice = (int)price;

        // String to number parsing
        string input = "500";
        int convertedInput = int.Parse(input);

        Console.WriteLine(name);
        Console.WriteLine(age);
        Console.WriteLine(salary);
        Console.WriteLine(maxLoginAttempts);
        Console.WriteLine(convertedNumber);
        Console.WriteLine(integerPrice);
        Console.WriteLine(convertedInput);
    }
}
```

Experiment by altering inputs and values to see how the compiler responds.
