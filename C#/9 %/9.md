# DAY 9 — 9%
## C# Methods — Parameters, Arguments, Return Types & `void`

Today starts **Methods**, an essential building block in C# Fundamentals. This module focuses on parameter mechanics, arguments, return types, the `void` keyword, the `return` statement, and foundational invocation flow.

The primary goal of this 1% is to understand **how methods structure program execution and how data moves into and out of them**.

---

### 1️⃣ What is a Method?

A **method** is a named, reusable block of code designed to perform a distinct operation.

Instead of writing redundant statements:

```csharp
Console.WriteLine("Hello");
Console.WriteLine("Hello");
Console.WriteLine("Hello");
```

Encapsulate the logic into a method:

```csharp
static void SayHello()
{
    Console.WriteLine("Hello");
}
```

Then invoke it by name:

```csharp
SayHello();
```

```
Define Method ──> Assign Name ──> Encapsulate Logic ──> Invoke When Needed
```

---

### 2️⃣ Basic Method Structure

```csharp
static void SayHello()
{
    Console.WriteLine("Hello");
}
```

#### Anatomy Breakdown:

* **`static`**: Method modifier (allows direct invocation on the class without instantiating an object).
* **`void`**: Return type (specifies that the method returns no data).
* **`SayHello`**: Identifier (PascalCase method name by C# convention).
* **`()`**: Parameter list (empty here, indicating no arguments required).
* **`{ }`**: Method body enclosing executable statements.

---

### 3️⃣ Defining vs. Calling a Method

Declaring a method merely defines its instructions. It **does not execute** until explicitly invoked:

```csharp
static void SayHello()
{
    Console.WriteLine("Hello");
}

static void Main()
{
    SayHello();
    SayHello();
}
```

#### Output:
```text
Hello
Hello
```

---

### 4️⃣ Parameters

A **parameter** is a placeholder variable declared in the method signature to accept incoming input:

```csharp
static void Greet(string name)
{
    Console.WriteLine($"Hello {name}");
}
```

* `string name` $\rightarrow$ Parameter declaration.

Invoking the method:

```csharp
Greet("Tony");
```

#### Output:
```text
Hello Tony
```

---

### 5️⃣ Parameter vs. Argument

This distinction is a frequent interview checkpoint:

* **Parameter:** The variable declared in the method definition signature.
* **Argument:** The actual concrete value supplied when invoking the method.

```csharp
// Method Definition: 'name' is the PARAMETER
static void Greet(string name)
{
    Console.WriteLine($"Hello {name}");
}

// Method Call: '"Tony"' is the ARGUMENT
Greet("Tony");
```

```
Method Definition ──> Parameter  (Variable placeholder)
Method Call       ──> Argument   (Literal / Evaluated value)
```

---

### 6️⃣ Multiple Parameters

Methods accept multiple parameters separated by commas. Values map by position:

```csharp
static void DisplayUser(string name, int age)
{
    Console.WriteLine($"Name: {name}");
    Console.WriteLine($"Age: {age}");
}
```

```csharp
DisplayUser("Tony", 22);
```

* `name` $\leftarrow$ `"Tony"`
* `age` $\leftarrow$ `22`

---

### 7️⃣ Return Types

When a method must produce an outcome for the caller to store or evaluate, declare a **return type** instead of `void`:

```csharp
static int Add(int a, int b)
{
    return a + b;
}
```

Calling the method and capturing its output:

```csharp
int result = Add(10, 20);
Console.WriteLine(result); // Output: 30
```

#### Data Flow:
```
Add(10, 20)
    ↓
a = 10, b = 20
    ↓
Evaluate: 10 + 20 = 30
    ↓
return 30
    ↓
Assigned to 'int result'
```

---

### 8️⃣ The `return` Keyword

The `return` statement serves two critical roles:

1. **Transfers Data:** Evaluates an expression and passes the resulting value back to the caller.
2. **Terminates Execution:** Immediately exits the method, bypassing any subsequent statements.

```csharp
static int CheckAge(int age)
{
    if (age >= 18)
    {
        return 1; // Exits immediately if condition evaluates to true
    }

    return 0; // Exits here if previous branch was skipped
}
```

---

### 9️⃣ The `void` Keyword

Use `void` when a method executes an action (such as logging, database writes, or state mutations) but produces no output value:

```csharp
static void PrintName(string name)
{
    Console.WriteLine(name);
}
```

```csharp
PrintName("Tony"); // ✅ Valid call

int result = PrintName("Tony"); // ❌ Compile Error: Cannot assign void to int
```

#### Return Type Comparison:

| Type | Output Behavior |
|---|---|
| `void` | Produces no return value |
| `int` | Yields a 32-bit signed integer |
| `string` | Yields a string reference |
| `bool` | Yields a boolean truth value (`true` / `false`) |

---

### 🔟 Common Return Type Patterns

```csharp
// Returns an integer
static int Square(int number)
{
    return number * number;
}

// Returns a string
static string GetMessage()
{
    return "Welcome";
}

// Returns a boolean predicate
static bool IsAdult(int age)
{
    return age >= 18;
}
```

Usage:

```csharp
bool result = IsAdult(22); // Evaluates to true
```

*Predicate methods returning `bool` are foundational for validation rules, conditional filters, and LINQ queries.*

### 1️⃣1️⃣ Method Call Chains & Composition

Methods can call other methods to compose higher-level workflows:

```csharp
static int Add(int a, int b)
{
    return a + b;
}

static void DisplayResult()
{
    int result = Add(10, 20);
    Console.WriteLine(result);
}

static void Main()
{
    DisplayResult();
}
```

#### Call Stack Progression:
```
Main()
  └── DisplayResult()
            └── Add(10, 20) ──> returns 30
      Prints 30
```

*This composition pattern mirrors enterprise layered architecture:*
```
Controller Action ──> Service Layer Method ──> Data Repository Method
```
