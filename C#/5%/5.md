# DAY 5 — 5%
## C# `switch` — Multiple Fixed Choices

Today covers **`switch`**, the next control-flow construct in your C# roadmap alongside `if`, `else`, `else if`, and loops.

The core principle:
**Use `switch` when comparing a single expression against multiple known, discrete values.**

---

### 1️⃣ Basic `switch` Syntax

```csharp
int day = 2;

switch (day)
{
    case 1:
        Console.WriteLine("Monday");
        break;

    case 2:
        Console.WriteLine("Tuesday");
        break;

    case 3:
        Console.WriteLine("Wednesday");
        break;

    default:
        Console.WriteLine("Invalid day");
        break;
}
```

#### Evaluation Flow:
```
day = 2
  ↓
switch (day)
  ↓
case 1? ──> ❌ No
case 2? ──> ✅ Yes ──> Prints "Tuesday" ──> break (exits switch)
```

#### Core Components:
* **`switch (expression)`**: Evaluates the target variable or expression once.
* **`case constant:`**: Defines a specific match target.
* **`break;`**: Terminates case execution and exits the switch block.
* **`default:`**: Fallback section executing when no case matches.

---

### 2️⃣ The Role of `break;`

In C#, fall-through from one executable case to another is prohibited. Every non-empty case block must end with a jump statement, usually `break`:

```csharp
case 2:
    Console.WriteLine("Tuesday");
    break; // Stops execution and transfers control out of the switch block
```

```
Case matched
     ↓
Execute statements
     ↓
break;
     ↓
Exit switch block
```

---

### 3️⃣ The `default` Label

The `default` label acts as a catch-all safety branch, equivalent to the final `else` in an `if / else if` ladder:

```csharp
int option = 10;

switch (option)
{
    case 1:
        Console.WriteLine("Login");
        break;

    case 2:
        Console.WriteLine("Register");
        break;

    default:
        Console.WriteLine("Invalid option");
        break;
}
```

Because `10` matches neither `case 1` nor `case 2`, control routes directly to `default`.

---

### 4️⃣ Multiple Statements in a Single Case

A single `case` block can execute multiple statements sequentially without needing curly braces:

```csharp
int option = 1;

switch (option)
{
    case 1:
        Console.WriteLine("Login selected");
        Console.WriteLine("Opening login page");
        break;

    case 2:
        Console.WriteLine("Register selected");
        break;

    default:
        Console.WriteLine("Invalid option");
        break;
}
```

---

### 5️⃣ Grouping Cases (Shared Behavior)

When multiple cases share identical execution logic, stack their `case` labels together:

```csharp
int day = 6;

switch (day)
{
    case 6:
    case 7:
        Console.WriteLine("Weekend");
        break;

    default:
        Console.WriteLine("Weekday");
        break;
}
```

* `6` $\rightarrow$ "Weekend"
* `7` $\rightarrow$ "Weekend"

Empty stacked cases are permitted and provide clean grouping for shared outcomes.

---

### 6️⃣ `switch` vs. `if / else if`

| Feature | `switch` | `if / else if` |
|---|---|---|
| **Best Used For** | Discrete, fixed, known values (`enum`, `int`, `string`, `char`) | Ranges, complex boolean expressions, dynamic comparisons |
| **Readability** | High when matching many specific values against one variable | Lower when evaluating long chains of single-variable equality |
| **Flexibility** | Evaluates a single target against static values | Can evaluate multiple distinct variables and logic operators (`&&`, `\|\|`) |

```csharp
// Range checking: Use if / else if
if (marks >= 90)
{
    Console.WriteLine("A");
}
else if (marks >= 75)
{
    Console.WriteLine("B");
}

// Discrete value checking: Use switch
switch (grade)
{
    case 'A':
        Console.WriteLine("Excellent");
        break;

    case 'B':
        Console.WriteLine("Good");
        break;
}
```

```
Discrete / Fixed Values ──> switch
Conditions / Ranges      ──> if / else if
```

---

### 7️⃣ Backend Scenario: Entity State Handling

`switch` is common in backend API workflows, such as checking finite order or payment states:

```csharp
string status = "Pending";

switch (status)
{
    case "Pending":
        Console.WriteLine("Order is being processed");
        break;

    case "Shipped":
        Console.WriteLine("Order has been shipped");
        break;

    case "Delivered":
        Console.WriteLine("Order delivered");
        break;

    case "Cancelled":
        Console.WriteLine("Order cancelled");
        break;

    default:
        Console.WriteLine("Unknown status");
        break;
}
```

---

### 8️⃣ Decision-Making vs. Loops

Do not confuse control branching with iteration:

```
if / switch             ──> Decision Making (Branching paths)
for / while / foreach   ──> Repetition (Iteration / Loops)
```
