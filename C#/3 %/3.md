### 1️⃣ Arithmetic Operators

Arithmetic operators perform standard mathematical calculations.

```csharp
int a = 20;
int b = 6;

Console.WriteLine(a + b); // 26 (Addition)
Console.WriteLine(a - b); // 14 (Subtraction)
Console.WriteLine(a * b); // 120 (Multiplication)
Console.WriteLine(a / b); // 3 (Division)
Console.WriteLine(a % b); // 2 (Modulus / Remainder)
```

| Operator | Name | Description |
|:---:|---|---|
| `+` | Addition | Adds two values |
| `-` | Subtraction | Subtracts the right operand from the left |
| `*` | Multiplication | Multiplies two values |
| `/` | Division | Divides the numerator by the denominator |
| `%` | Remainder / Modulus | Returns the division remainder |

#### ⚠️ Integer Division vs. Floating-Point Division

When both operands are integers, C# performs **integer division**, which discards (truncates) any fractional part:

```csharp
int result = 10 / 3;
Console.WriteLine(result); // Output: 3
```

To preserve decimal precision, at least one operand must be a floating-point type:

```csharp
double result = 10.0 / 3;
Console.WriteLine(result); // Output: 3.3333333333333335
```

### 2️⃣ Assignment Operators

The primary assignment operator is `=`:

```csharp
int x = 10;
```

#### Compound Assignment Operators

Compound operators combine an arithmetic operation with assignment:

| Operator | Example | Equivalent To |
|:---:|---|---|
| `+=` | `x += 5;` | `x = x + 5;` |
| `-=` | `x -= 2;` | `x = x - 2;` |
| `*=` | `x *= 3;` | `x = x * 3;` |
| `/=` | `x /= 2;` | `x = x / 2;` |
| `%=` | `x %= 2;` | `x = x % 2;` |

**Example:**

```csharp
int balance = 1000;
balance += 500;
Console.WriteLine(balance); // Output: 1500
```

### 3️⃣ Comparison Operators

Comparison operators evaluate the relationship between two operands and return a `bool` (`true` or `false`).

```csharp
int age = 22;

Console.WriteLine(age == 22); // True
Console.WriteLine(age != 18); // True
Console.WriteLine(age > 18);  // True
Console.WriteLine(age < 30);  // True
Console.WriteLine(age >= 18); // True
Console.WriteLine(age <= 25); // True
```

| Operator | Meaning |
|:---:|---|
| `==` | Equal to |
| `!=` | Not equal to |
| `>` | Greater than |
| `<` | Less than |
| `>=` | Greater than or equal to |
| `<=` | Less than or equal to |

**Example:**

```csharp
int salary = 50000;
bool result = salary >= 30000; // result = true
```

---

### 4️⃣ Logical Operators

Logical operators combine or invert `bool` values.

#### AND — `&&`
Returns `true` **only if both** conditions evaluate to `true`.

```csharp
int age = 25;
bool hasId = true;
bool allowed = age >= 18 && hasId; // true
```

#### OR — `||`
Returns `true` if **at least one** condition evaluates to `true`.

```csharp
bool hasTicket = false;
bool isVip = true;
bool allowed = hasTicket || isVip; // true
```

#### NOT — `!`
Inverts the truth value.

```csharp
bool isLoggedIn = true;
Console.WriteLine(!isLoggedIn); // Output: False
```

#### Truth Table

| A | B | A && B | A \|\| B |
|:---:|:---:|:---:|:---:|
| `true` | `true` | `true` | `true` |
| `true` | `false` | `false` | `true` |
| `false` | `true` | `false` | `true` |
| `false` | `false` | `false` | `false` |

* `!true` $\rightarrow$ `false`
* `!false` $\rightarrow$ `true`

### 5️⃣ Increment and Decrement Operators

Used to increase or decrease a numeric value by 1.

#### Postfix vs. Prefix

* **Postfix (`x++`, `x--`):** Uses the current value first, then increments/decrements.
* **Prefix (`++x`, `--x`):** Increments/decrements first, then evaluates the updated value.

```csharp
int count = 5;

count++; // count is now 6
count--; // count is back to 5
```

---

### 6️⃣ Operator Precedence

Expressions are evaluated according to predefined operator precedence, not strictly left-to-right.

```csharp
int result = 10 + 5 * 2;
// 5 * 2 = 10
// 10 + 10 = 20
// result = 20
```

Use parentheses `()` to override default precedence:

```csharp
int result = (10 + 5) * 2;
// (10 + 5) = 15
// 15 * 2 = 30
// result = 30
```

#### Evaluation Hierarchy:
```
()              (Parentheses)
 ↓
*  /  %         (Multiplicative)
 ↓
+  -            (Additive)
```
