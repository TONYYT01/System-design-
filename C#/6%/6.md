# DAY 6 — 6%
## C# `for` Loop + Nested `for` Loops

Today marks the transition from **decision-making $\rightarrow$ repetition**.

The `for` loop is a core control-flow structure. The primary objective is to master the **internal execution lifecycle** of a `for` loop rather than simply memorizing its syntax.

---

### 1️⃣ Why Do We Need Loops?

Consider printing numbers from 1 to 5:

```csharp
// Without a loop: highly repetitive and unmaintainable
Console.WriteLine(1);
Console.WriteLine(2);
Console.WriteLine(3);
Console.WriteLine(4);
Console.WriteLine(5);
```

Using a loop:

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}
```

> **Definition:** A loop repeatedly executes a target block of code as long as its controlling conditional expression evaluates to `true`.

---

### 2️⃣ Anatomy of the `for` Loop

The syntax consists of three distinct control clauses:

```csharp
for (initialization; condition; iteration)
{
    // loop body
}
```

#### Clause Breakdown:

```
for
 │
 ├── initialization ──> int i = 1   (Executes exactly ONCE at loop entry)
 │
 ├── condition      ──> i <= 5      (Evaluated BEFORE every iteration)
 │
 └── iteration      ──> i++         (Executes AFTER every iteration body)
```

#### Step-by-Step Execution Lifecycle:

```
1. Initialization (int i = 1)
        ↓
2. Condition Check (1 <= 5? True)
        ↓
3. Execute Body (Prints 1)
        ↓
4. Iteration Step (i++ → i becomes 2)
        ↓
5. Condition Check (2 <= 5? True)
        ↓
   ... repeats ...
        ↓
   Iteration Step (i++ → i becomes 6)
        ↓
6. Condition Check (6 <= 5? False)
        ↓
7. Terminate & Exit Loop
```

*This execution order is a staple question in technical assessments.*

### 5️⃣ Modifying Step Intervals & Backward Traversal

You are not limited to `i++`.

#### Incrementing by 2:
```csharp
for (int i = 0; i <= 10; i += 2)
{
    Console.WriteLine(i);
}
// Outputs: 0, 2, 4, 6, 8, 10
```

#### Decrementing (Reverse Loop):
```csharp
for (int i = 10; i >= 1; i--)
{
    Console.WriteLine(i);
}
// Outputs: 10, 9, 8, ... 1
```

---

### 6️⃣ `i++` vs. `i += 2`

* `i++` $\rightarrow$ Increments by 1 (`i = i + 1`)
* `i += 2` $\rightarrow$ Increments by 2 (`i = i + 2`)

```csharp
for (int i = 1; i <= 10; i += 3)
{
    Console.WriteLine(i);
}
// Outputs: 1, 4, 7, 10
```

### 7️⃣ Combining Loops with Conditions

By embedding conditional checks (`if`), you connect multiple fundamentals:

```csharp
for (int i = 1; i <= 20; i++)
{
    if (i % 2 == 0)
    {
        Console.WriteLine(i);
    }
}
// Outputs: 2, 4, 6, 8, ... 20
```

### 8️⃣ Nested `for` Loops

A nested loop is a loop declared inside the body of another loop:

```csharp
for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        Console.WriteLine($"i={i}, j={j}");
    }
}
```

#### Execution Order:
```
i = 1 ──> j = 1, j = 2, j = 3
i = 2 ──> j = 1, j = 2, j = 3
i = 3 ──> j = 1, j = 2, j = 3
```

> **Core Rule:** The inner loop completes its **entire lifecycle** for every single iteration of the outer loop.

---

### 9️⃣ Pattern Generation Using Nested Loops

```csharp
for (int i = 1; i <= 5; i++)
{
    for (int j = 1; j <= i; j++)
    {
        Console.Write("* ");
    }
    Console.WriteLine();
}
```

Output:
```text
* 
* * 
* * * 
* * * * 
* * * * * 
```

Because the inner loop's termination condition relies on `j <= i`, the number of iterations scales dynamically with the outer counter.
