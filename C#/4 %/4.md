# DAY 4 — 4%
## C# Conditions: `if`, `else if`, `else` + Nested Conditions

Today we move into **Control Flow**. The roadmap covers `if`, `else`, `else if`, and `switch`—focusing here on conditional branch statements first.

The core purpose of conditions: **direct application execution paths based on Boolean evaluations.**

---

### 1️⃣ The `if` Statement

The foundational decision-making construct:

```csharp
if (condition)
{
    // Code block executes only when condition evaluates to true
}
```

#### Example:

```csharp
int age = 20;

if (age >= 18)
{
    Console.WriteLine("Eligible");
}
```

#### Execution Path:
```
age = 20
   ↓
20 >= 18 evaluates to true
   ↓
Executes inside block → Prints: "Eligible"
```

If the condition evaluates to `false`, the runtime skips the block entirely.

---

### 2️⃣ `if` with Comparison Operators

Conditional statements evaluate expressions that produce a `bool`:

```csharp
int marks = 75;
if (marks >= 40)
{
    Console.WriteLine("Pass");
}

int balance = 5000;
if (balance > 1000)
{
    Console.WriteLine("Sufficient balance");
}
```

---

### 3️⃣ The `else` Statement

The `else` block executes when the matching `if` condition evaluates to `false`.

```csharp
int age = 16;

if (age >= 18)
{
    Console.WriteLine("Adult");
}
else
{
    Console.WriteLine("Minor");
}
```

#### Branch Flow:
```
             age >= 18?
             /        \
         true          false
          ↓              ↓
      "Adult"         "Minor"
```

Only **one** branch will execute.

---

### 4️⃣ The `else if` Ladder

When you have multiple mutually exclusive conditions, link them using `else if`:

```csharp
int marks = 75;

if (marks >= 90)
{
    Console.WriteLine("A");
}
else if (marks >= 75)
{
    Console.WriteLine("B");
}
else if (marks >= 40)
{
    Console.WriteLine("C");
}
else
{
    Console.WriteLine("Fail");
}
```

#### Key Execution Rule:
C# evaluates conditions **sequentially from top to bottom**. As soon as one branch evaluates to `true`, its block executes and the rest of the chain is skipped.

```
marks = 75
  ↓
75 >= 90 → false (continue)
  ↓
75 >= 75 → true  (execute block → print "B", skip all remaining branches)
```

---

### 5️⃣ Combining Conditions with AND (`&&`)

All conditions joined by `&&` must evaluate to `true` for the block to run.

```csharp
int age = 25;
bool hasId = true;

if (age >= 18 && hasId)
{
    Console.WriteLine("Allowed");
}
```

```
age >= 18  → true
hasId      → true
true && true → true → Prints "Allowed"
```

---

### 6️⃣ Combining Conditions with OR (`||`)

If **at least one** condition evaluates to `true`, the block runs.

```csharp
bool isAdmin = false;
bool isManager = true;

if (isAdmin || isManager)
{
    Console.WriteLine("Access granted");
}
// false || true → true → Prints "Access granted"
```

---

### 7️⃣ Inverting Conditions with NOT (`!`)

Inverts the evaluation of any Boolean expression.

```csharp
bool isBlocked = false;

if (!isBlocked)
{
    Console.WriteLine("User can access");
}
// !false → true → Block executes
```

---

### 8️⃣ Nested `if` Statements

An `if` statement placed inside another `if` block creates layered criteria:

```csharp
int age = 25;
bool hasLicense = true;

if (age >= 18)
{
    if (hasLicense)
    {
        Console.WriteLine("Can drive");
    }
}
```

#### Equivalent Logical Representation:
```csharp
if (age >= 18 && hasLicense)
{
    Console.WriteLine("Can drive");
}
```

> **Design Note:** Use nested blocks when subsequent branches need different `else` fallbacks or deeper validation steps. Use `&&` when you just want a single clean guard clause.

---

### 9️⃣ Real-World Backend Pattern

Conditional business logic is ubiquitous in web APIs and services:

```csharp
string status = "Pending";

if (status == "Pending")
{
    Console.WriteLine("Order can be cancelled");
}
else
{
    Console.WriteLine("Order cannot be cancelled");
}
```

This pattern underpins validation in ASP.NET Core endpoints, database checks, and domain entities.

```csharp
class Program
{
    static void Main()
    {
        string name = "Tony";
        int age = 24;

        if (age >= 21 && hasDegree)

            else
            {
                Console.WriteLine("Not enough experience");

        }
        else
        {
            Console.WriteLine("Basic eligibility not satisfied");
        }
    }
}
```
