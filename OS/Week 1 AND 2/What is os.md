## What is os

- The os is the one of the software that is act as teh bridge between the user and the hardware

- Without os you system is just an expensive one

### It manages 

- Cpu (Who gets process time)
- Memory (Ram Usage)
- Files (Storage)
- Devices (Keyboard,mouse,printer,display)

- Types of OS's
    - Windows
    - Mac
    - linux

### Os does 5 main Jobs

1. Process management
    - Run programs (Processes)
    - Decides who runs first(Scheduling)
2. Memeory management 
    - Allocate the memory
    - prevent programs from interfering
3. File management
    - Organizes files like folders
4. Device Management
    - Controls hardware via drivers
5. security 
    - User account,permissions

### Types of os's

1. Batch Operating system

- No interaction we just submit the job -> system run them in batches

##### How it works
- Jobs are collected
- Runs one after another
- No user interaction during the execution

2. Time-sharing operating system

- Many users share the cpu at the same time 
- Like netflix - Everyone streaming but system handles it smoothly

3. Distributed Operating system

- The group of systems are work together like one system

##### How it works

- tasks are devided into multiple machines
- Results are combined
